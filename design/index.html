Argon Pull Request Client — Estudo de Design

Escolha abaixo uma das 3 propostas de interface interativas criadas para estudo de design e validação de fluxo de trabalho.

PROPOSTA 1

Zed Native Tri-Pane

Inspirada na estética limpa do editor Zed e clientes de alta produtividade (Superhuman). Layout estruturado em 3 colunas nativas ultra-rápidas.

  • ✓ 3 Colunas: Caixas de Entrada, Lista e Detalhes
  • ✓ Drawer retrátil de IA acionado por atalho ou botão
  • ✓ Modal para seleção de runner (Claude, Codex, etc.)
  • ✓ Tabs superiores: Commits, Actions, Review
  • ✓ Visualizador de Diff inline e side-by-side

PROPOSTA 2

Linear Modern Deck

Inspirada no Linear e Raycast. Experiência ampla com Agent Copilot Inspector permanente na lateral direita para acompanhamento contínuo de revisões.

  • ✓ Sidebar ultra-limpa com contadores minimalistas
  • ✓ Side-by-Side Diff real com painel duplo
  • ✓ Inspector de IA fixo à direita para chat simultâneo
  • ✓ Seletor rápido de modelo de IA diretamente no inspetor
  • ✓ Navegação rápida de PRs via atalhos de teclado (J/K)

PROPOSTA 3

PR Flow Enhanced

Evolução direta do print de referência enviado. Preserva a hierarquia visual fiel do PR Flow e expande com Drawer deslizante para inspeção profunda de código.

  • ✓ Sidebar com Priority, Views, Groups, Repos e Contas
  • ✓ Linhas de PR idênticas ao print com ícones densos
  • ✓ Modal Slide-over amplo para o PR selecionado
  • ✓ Integração visual com GitHub CLI (`gh`)
  • ✓ Chat com IA integrado dentro do próprio Drawer do PR

Especificações Contempladas nas 3 Propostas

1. Caixas de Entrada (Inbox)

Inbox (cronológico), Needs You, Your PRs, Waiting Others, Changes Requested, Ready to Merge e Already Done com filtros por orgs/repos.

2. Abas do PR

Commits (histórico com hashes), Actions (CI checks com status e duração), e Review (Diff side-by-side e inline com ações de aprovação).

3. Reviews com Agentes de IA

Suporte nos mockups para Claude Code, OpenCode, Codex, Antigravity e CommandCode, com seleção de modelos (Sonnet, Opus, etc.), customização de prompts e chat interativo.
